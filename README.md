# golivingbest

The golivingbest family is a free-to-use software suite for sales distribution, inventory management, and AI-assisted workflows.

It currently includes:
- **glb_ops**: a sales distribution and inventory management system
- **glb_ai**: an AI assistant for OCR and data analysis

We also provide software customization services for organizations interested in adopting golivingbest family products.

Visit our website: **www.golivingbest.com**
